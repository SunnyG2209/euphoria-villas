# Euphoria Villa Website

Luxury villa landing website for Euphoria Villa, Vijayawada.

## Local setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages deployment

1. Create a GitHub repository named `euphoria-villas` under `SunnyG2209`.
2. Push this project to the repository.
3. Install dependencies:

```bash
npm install
```

4. Deploy:

```bash
npm run deploy
```

The site will be available at:

```text
https://SunnyG2209.github.io/euphoria-villas/
```

## Notes

- The contact form is currently static and only shows an on-page success message.
- Connect the form later to Google Forms, Formspree, Netlify Forms, or a CRM.
- The official brochure is included in `public/euphoria-villa-brochure.pdf`.
